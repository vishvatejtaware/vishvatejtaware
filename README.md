## ⭐ Featured Academic Project

### ⛽ AI-Powered Real-Time CNG Station Recommendation System

A smart system designed to recommend a suitable CNG station using real-time parameters:

- CNG Availability
- CNG Pressure
- Vehicle Queue Length
- Distance from User
- Travel Time
- Waiting Time

### ⚙️ Technologies

`Python` `Random Forest` `YOLOv8` `IoT` `ESP32` `MQTT` `REST API`

### 📊 Project Results

- **R² Score:** 0.97
- **MAE:** 0.05
- **RMSE:** 0.08

The system uses **YOLOv8** for vehicle queue detection and **Random Forest Regression** for CNG station ranking.

IoT sensors and ESP32 are used to collect station information, while MQTT/API communication helps transfer real-time data.
